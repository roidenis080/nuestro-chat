NUESTRO CHAT ❤️

1. Instala Node.js.
2. Abre una terminal dentro de esta carpeta.
3. Ejecuta:
   npm install
4. Luego:
   npm start
5. Abre http://localhost:3000

IMPORTANTE:
- Esto es una primera versión funcional.
- Para que tu novia pueda entrar desde otra red, debes publicar el servidor en un hosting/VPS o configurar acceso externo seguro.
- Los mensajes actualmente se guardan solo en memoria del servidor: al reiniciarlo se borran.
- Antes de usarlo para datos privados, añade HTTPS, autenticación real y una base de datos.
